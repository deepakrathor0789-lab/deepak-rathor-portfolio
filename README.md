## 📖 About

A modern, responsive personal portfolio website built with **React.js** and **Tailwind CSS**. This portfolio showcases my skills, projects, and experience as a **Java Full Stack Developer**. It features a sleek dark/light mode, smooth animations, and a professional design.

### 🌟 Features

- ✅ **Dark/Light Mode** - Toggle between themes seamlessly
- ✅ **Responsive Design** - Optimized for all screen sizes
- ✅ **Smooth Animations** - Powered by Framer Motion
- ✅ **Typed.js Integration** - Dynamic text animations
- ✅ **Interactive UI** - Hover effects and transitions
- ✅ **Download Resume** - One-click resume download
- ✅ **Project Showcase** - Display featured projects with GitHub links
- ✅ **Professional Layout** - Clean and modern design
- ✅ **SEO Friendly** - Meta tags and semantic HTML
- ✅ **Performance Optimized** - Built with Vite

## 🚀 Getting Started

### Prerequisites

- **Node.js** (v18 or higher)
- **npm** (v9 or higher)

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/deepakrathor0789-lab/portfolio.git

# 2. Navigate to project directory
cd portfolio

# 3. Install dependencies
npm install

# 4. Start development server
npm run dev

# 5. Build for production
npm run build

# 6. Preview production build
npm run preview
